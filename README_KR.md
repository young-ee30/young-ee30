## 👋 About Me

안녕하세요.
**안전하고 운영 가능한 클라우드 인프라를 설계하는 보안 엔지니어**를 목표로 성장하고 있는 **이가영**입니다.

AWS와 Linux 환경을 기반으로 인프라를 구축하고,
**IAM 권한 관리, 네트워크 접근통제, IaC 보안 검증, CI/CD 보안 자동화, 로그 모니터링**을 하나의 운영 흐름으로 연결하는 데 관심이 있습니다.

단순히 취약점을 발견하는 것에 그치지 않고,
보안 기준을 코드와 자동화된 파이프라인에 반영하여 **지속적으로 점검하고 개선할 수 있는 구조**를 만드는 것을 지향합니다.

현재는 AWS, Terraform, Docker, GitHub Actions, Linux를 중심으로
클라우드 인프라 구축과 보안 운영 역량을 함께 학습하고 있습니다.

* 비인가 명령 전송 가능성 검증
* 통신 인증과 키 관리의 중요성 분석
* 실험 과정 및 보안 대응방안 문서화
