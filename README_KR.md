## 👋 소개

안녕하세요! 보안 솔루션을 직접 만들고 적용하는 보안 엔지니어 **이가영**입니다.

**"복잡한 시스템을 안전하게, 그리고 스마트하게 자동화합니다."**

취약점을 직접 발굴하는 오펜시브(Offensive) 관점과 안전한 시스템을 짓는 디펜시브(Defensive) 관점을 모두 가지고 있습니다. 단순히 문제를 짚어내는 것을 넘어, **실질적인 해결책을 자동화된 플랫폼과 파이프라인으로 구현**하는 일에 집중하고 있습니다. 😊

- ☁️ 인프라를 코드로 안전하게 관리하는 **AWS 기반 DevSecOps 파이프라인** 설계
- 📊 대규모 서버 환경에서 **취약점 점검부터 조치, 보고서까지 자동화**하는 플랫폼 구축 (KISA 기준)
- 🚁 MAVLink 프로토콜 취약점 분석 및 펌웨어 리버싱을 활용한 **하드웨어 보안 연구**
